# Citation

If you use **scPyviewer** in your research, please cite:

> Xuan, H., Huang, Y., Bian, J., & Liu, X. (2026). *scPyviewer: a Python-native
> interactive viewer from AnnData single-cell data.* bioRxiv.
> doi:[10.64898/2026.08.26.747418](https://www.biorxiv.org/content/early/2026/08/31/2026.08.26.747418)

## BibTeX

```{code-block} bibtex
@article{Xuan2026scPyviewer,
  author    = {Xuan, Hao and Huang, Yu and Bian, Jiang and Liu, Xiangtao},
  title     = {scPyviewer: a Python-native interactive viewer from AnnData single-cell data},
  year      = {2026},

  publisher = {Cold Spring Harbor Laboratory},
  journal   = {bioRxiv},
  url       = {https://www.biorxiv.org/content/early/2026/08/31/2026.08.26.747418}
}
```

The repository also ships a [`CITATION.cff`](https://github.com/xuan13hao/scPyviewer/blob/main/CITATION.cff)
file, so GitHub's **“Cite this repository”** button exports APA / BibTeX
automatically.

Please also cite the underlying tools scPyviewer builds on — notably
[scanpy](https://scanpy.readthedocs.io/) and
[anndata](https://anndata.readthedocs.io/) — where appropriate.
